# Daily Routine Productivity App

A beautifully designed Flutter application to manage your daily tasks, track your progress, and stay productive.

## Features

*   **Routines Tracking:** Easily view and manage your daily routines.
*   **Progress Statistics:** Track your productivity and stay motivated with detailed stats.
*   **User Profile:** Customize your app experience and personal settings.
*   **Modern UI:** Clean, minimalist design utilizing custom fonts (Inter).

## Screens

1.  **Routines Screen:** Your hub for daily tasks.
2.  **Stats Screen:** Visual representation of your progress.
3.  **Profile Screen:** Manage your account and app settings.

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites

*   Flutter SDK (^3.11.3)
*   Dart SDK

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2.  Navigate to the project directory:
    ```bash
    cd productivity_app
    ```
3.  Install dependencies:
    ```bash
    flutter pub get
    ```
4.  Run the app:
    ```bash
    flutter run
    ```

## Project Structure

*   `lib/main.dart`: Entry point of the application.
*   `lib/bottom_navigation_screen.dart`: Manages the main navigation between different sections.
*   `lib/routines_screen.dart`: UI for the daily routines.
*   `lib/stats_screen.dart`: UI for the statistics.
*   `lib/profile_screen.dart`: UI for the user profile.
*   `assets/`: Contains custom fonts used in the app (Inter).
